## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mahenaj-tabassum/Portfolio_website
```

### 2. Navigate to the project

```bash
cd Portfolio_website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.

## 📦 Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## 🎨 Design Goals

The portfolio was designed around a few principles:

**Clarity**
Keep the content easy to scan and understand.

**Responsiveness**
Make the experience work smoothly across different screen sizes.

**Simplicity**
Avoid unnecessary visual complexity and keep the focus on the content.

**Reusability**
Build the interface using reusable React components instead of one large component.

**Performance**
Keep the application lightweight and avoid unnecessary dependencies.
